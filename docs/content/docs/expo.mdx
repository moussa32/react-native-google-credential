## Expo support

When you run an Expo project on the web, the package uses its web implementation
with Google Identity Services.

The Expo Go native app cannot load this package's custom Android or iOS module.
To test Android Credential Manager, create and install an Android development
build:

```bash
npx expo run:android
```

You can also use an EAS development build. Use `npx expo start --web` when you
only need to test the web implementation.

## Config plugin

Add the plugin to your Expo config:

```ts
export default {
  plugins: [
    [
      '@pricava/react-native-google-credential',
      {
        iosClientId: process.env.GOOGLE_IOS_CLIENT_ID,
        iosUrlScheme: process.env.GOOGLE_IOS_URL_SCHEME,
      },
    ],
  ],
};
```

The plugin writes:

- `GIDClientID` to `Info.plist` when `iosClientId` is provided.
- The iOS URL scheme from `iosUrlScheme`, or derives it from `iosClientId`.

The plugin also reads `GOOGLE_IOS_CLIENT_ID` and `GOOGLE_IOS_URL_SCHEME` from
the environment when those props are omitted.

## Runtime support

Expo development builds use the same React Native TurboModule/native module as
bare React Native apps. The Expo config plugin only handles iOS native
configuration.

## React Native Firebase adapter

The Firebase adapter is optional. When you use it, configure React Native
Firebase separately and keep its App and Auth packages on the same version.
This package supports React Native Firebase Auth from `24.1.1` through `26.x`.

React Native Firebase 24 and 25 use its CocoaPods/static-framework Expo setup.
React Native Firebase 26 uses Swift Package Manager and dynamic frameworks by
default on supported React Native versions. Follow the
[React Native Firebase Expo installation guide](https://rnfirebase.io/#installation-for-expo-projects)
for the exact version in your project; this package does not modify Firebase's
Podfile linkage.

## Rebuild after config changes

Any native config change requires rebuilding the app:

```bash
npx expo prebuild --clean
npx expo run:ios
npx expo run:android
```

For EAS builds, commit the config changes and trigger a new build.
